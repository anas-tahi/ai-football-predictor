## ✨ Features

- 🧠 AI model trained on historical match data
- 📊 Win / Draw / Loss probability output
- 🏆 Supports major European leagues
- ⚡ TypeScript — fully typed codebase
- ☁️ Deployed live on Render

## 🛠️ Tech Stack

| Layer | Tech |
|---|---|
| Language | TypeScript |
| Runtime | Node.js |
| AI/ML | Custom prediction model |
| Deployment | Render |

## 🚀 Run Locally

```bash
git clone https://github.com/anas-tahi/ai-football-predictor
cd ai-football-predictor
npm install
npm run predict
```
